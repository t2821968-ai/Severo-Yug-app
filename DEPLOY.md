# Публикация сайта

Проект подготовлен для публикации на Render через Blueprint из `render.yaml`.

## Публикация

1. Создай GitHub-репозиторий и загрузи в него файлы проекта. Не загружай `.env`, `data/users.json` или `data/market.json`.
2. В Render выбери **New → Blueprint**, подключи репозиторий и подтверди создание сервиса `severo-yug`.
3. Дождись успешного деплоя и открой адрес сервиса вида `https://severo-yug.onrender.com`.
4. Проверь `/healthz`, затем открой главную страницу и зарегистрируй аккаунт.

Blueprint настраивает Node.js-сервис, production cookie, секрет сессии и постоянный диск для аккаунтов и лотов. Постоянный диск Render доступен на платном плане Starter; без него JSON-данные могут пропасть при перезапуске или новом деплое. Перед публикацией проверь актуальную стоимость плана в Render.

## Локальный запуск

```powershell
npm ci
npm start
```

Открой `http://localhost:3000`. Для локального production-режима задай `NODE_ENV=production` и длинный случайный `SESSION_SECRET`.
